# Two-minute demonstration

Rehearse with two independent browser contexts already admitted to one room. Keep startup/login out of the recording. Use synthetic material only.

| Time | Demonstration |
| --- | --- |
| 0–15s | “A rewrite changed a customer promise. LegacyDiff makes the difference reviewable and testable.” Show the two pinned source variants. |
| 15–40s | Start one comparison without AI. Show the actual day-30 outputs: $100 eligible baseline versus $0 ineligible rewrite. Matching controls remain in Cases. |
| 40–70s | Show the conflicting handbook and migration ticket. B adds a comment or evidence pin that appears in A. Explain that neither code nor an agent settles policy automatically. |
| 70–100s | Publish an exact proposal, review its five expected cases and evidence, approve in B. Show the measured failing validation and the same decision in both clients. |
| 100–115s | Download the bundle and run `python -I acceptance_tests.py` outside the app. Its expected failure preserves the decision. If time permits, show the separately supplied corrected fixture comparison. |
| 115–120s | “The policy decision now survives as an executable test.” |

Both the deterministic rehearsal and a real four-role NVIDIA Ultra run are verified. A measured live team run took 81.7 seconds, so start it before a two-minute presentation and clearly identify the completed saved run when showing its actual handoffs and validated suggestions. Do not imply the model work finishes in the 30-second narration slot. A new run may fail or return partial work; keep those states visible. A recording must be labeled recorded.

For live judging, also demonstrate: stale approval rejected after another participant publishes a revision; local rationale retained; unauthorized third identity denied; a deferred finding creates no acceptance tests; an Exclude day 30 decision can pass the original rewrite. These checks need more than the two-minute recording.

Use the actual latest verification report when describing what works. Do not claim arbitrary repository ingestion, autonomous repair, universal equivalence, Docker isolation, sponsor eligibility, submission or public deployment.
